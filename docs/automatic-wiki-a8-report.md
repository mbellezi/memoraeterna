Status: independently accepted on 2026-09-13. A0–A8 are complete for the requested

## Final acceptance corrections

The combined journey exposed raw-context domination at the new generous remote
context budget. The successor consultation packer correctly loaded compiled
knowledge and its originals first, but then filled ten remaining slots with
repetitive, unrelated lexical matches. Complementary raw expansion now cannot
exceed the selected compiled originals in count or serialized UTF-8 evidence
bytes. Whole-passage omission preserves exact evidence and reports limited
coverage. No-compiled raw fallback, legacy consultation ranking and already
admitted snapshots are unchanged. This is a bounded-volume guarantee, not a
semantic filter or a claim that every irrelevant passage is excluded.

The new regression uses twelve noisy candidates, including an oversized passage,
at 128,000 context. It checks intact compiled support, bounded complementary
originals, whole-passage omission and the original-only fallback. Real PostgreSQL
A5 additionally verifies that genuinely new C evidence can refresh a followed
question before its topic is regenerated, preserving the earlier answer/gaps.

The first unpacked artifact's runtime manifest included a Docling `.gitkeep` that
electron-builder omitted. Staging now excludes that repository placeholder before
inventory/checksum generation. The new static artifact verifier checks actual
delivered file hashes, seed/journal parity, archive contents and module startup.
It never launches a packaged app or a local model.

The third correction came from actual Obsidian1.13.7 reading: section reference
lines written as `- [1] [[…]]` appeared as checked task boxes. They now use ordinary
ordered links (`1. [[…]]`), preserving section-local order, exact evidence anchors,
source labels and excerpts. The existing layout PostgreSQL/temporary-vault verifier
first reproduced the failure, then checked both ordered citations and unchanged
canonical page/evidence after migration. Citation numbering grants no task or
review state. The regression uses a separate page so its evidence dependencies
do not interfere with the existing source-edit/merge-base conflict scenario.

The fourth actual-editor finding was a dead source-opening link on the merged
note's deleted primary original. Both layout2 and retained-note/page citations
in format1 now retain the historical source title and exact excerpt with the
localized unavailable label, without a source-opening action. A live original
without a projected file still has its valid application link. Existing
scope/excluded-source guards and historical currentness remain unchanged.
The expanded A7 populated/empty PostgreSQL verifier checks primary deletion,
both exact original snapshots, surviving source links, and real temporary
format1 delivery with a live but unprojected source. No personal vault or frozen
coordinator editor fixture was modified by these implementation changes.
