Sobre

Esta árvore foi construída automaticamente, sem LLM, a partir dos embeddings das notas. Os nomes são provisórios: termos TF-IDF no formato “Pai › termos”. Na versão final, um modelo dará títulos de verdade aos tópicos.

    Como avaliar

    1. Leia as 8 notas sorteadas de cada tópico (o título vem do artigo e da seção de origem).
    2. Coerente: “Sim” se as notas tratam claramente de um mesmo assunto, que você colocaria numa mesma pasta. Uma ou outra nota destoante ainda pode ser “Sim”.
    3. Bem nomeado: “Sim” se o nome provisório indica esse assunto, mesmo sendo só uma lista de termos.
    4. As respostas ficam salvas neste navegador. Ao terminar, use Exportar respostas e cole o JSON de volta na conversa.
